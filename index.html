Privacy Policy

Local-First Storage No User Tracking No Account Required Edge & Firefox Editions

1. Overview & Core Philosophy

Bookmark Glass is a minimal browser bookmark manager, personal link library, and article reading tracker designed with privacy-first principles. This Privacy Policy applies to all official builds of Bookmark Glass, including the Microsoft Edge and Mozilla Firefox editions.

Both editions operate with a strict local-first architecture. We do not operate user accounts, cloud databases, synchronization servers, or telemetry collectors. Your saved links, personal notes, custom tags, and reading lists remain entirely on your computer.

2. What Data Is Stored Locally on Your Device

All data created or organized in Bookmark Glass is saved locally in your browser's dedicated extension storage:

Data Category Storage Mechanism Purpose
Browser Bookmarks browser.bookmarks / chrome.bookmarks Reads and syncs with your browser's native bookmark and favorites hierarchy.
Personal Library Links chrome.storage.local (key: my_library_links) Stores saved links, custom titles, tags, notes, and favorite flags.
Articles & Reading List chrome.storage.local (key: my_articles_library) Stores saved articles with reading statuses (Want to Read, In Progress, Done Reading) and notes.
Folders & Visual Metadata chrome.storage.local (keys: custom_library_folders, folder_visual_metadata) Stores custom library folder trees and visual folder color accents.
User Settings & Preferences chrome.storage.local (key: bookmark_glass_settings) Stores independent layout preferences (grid, list, title), theme, and destination defaults.
Recent Tags Cache localStorage (keys: bg-tagpool-lib, bg-tagpool-art in Edge; bg-tagpool in Firefox) Stores recently typed tags locally for autocomplete and quick-tagging convenience.

3. Favicon Resolution & External Requests

Bookmark Glass does not transmit your personal data, saved notes, or reading history to any proprietary servers. Favicon resolution operates as follows depending on your browser edition:

Microsoft Edge Native Local Favicon Resolution (Zero External Transmission):

The Microsoft Edge edition retrieves website icons entirely locally through Chromium's extension endpoint (/_favicon/) supported by the favicon permission. Icons are served directly from Edge's local browser cache. No website URLs, domain names, or IP addresses are transmitted to any external third-party server.

Mozilla Firefox External Favicon Service:

Because Firefox's WebExtensions API does not provide an equivalent local favicon cache endpoint, the Firefox edition loads website icons using the public Google Favicon endpoint:
https://www.google.com/s2/favicons?domain=[domain]&sz=64

  • What is transmitted: Only the web domain name or origin (e.g., github.com or wikipedia.org) of the saved link is included in the image request.
  • What is NOT transmitted: Full page URLs, pathnames, search query strings, user notes, tags, or personal identifiers are never sent.
  • Provider: Google LLC. Requests are subject to Google's Privacy Policy.

Shared Network Disclosures (Both Editions)

Voluntary Feedback Form: The extension dashboard includes an optional feedback banner linking to a Google Form. Clicking "Share Feedback" opens the form in a new tab. Submitting feedback is completely optional and handled directly on Google Forms.

No Telemetry, Analytics, or Tracking: Neither edition integrates Google Analytics, Mixpanel, Sentry, or any third-party telemetry, tracking, or advertising scripts.

4. Mozilla Firefox Data Collection Declarations

Under Mozilla's built-in consent framework for Firefox Add-ons, the Firefox edition of Bookmark Glass declares the following data collection permissions in manifest.json:

  • Bookmarks (bookmarksInfo): Declared because domain information from your saved bookmarks is queried against the Google Favicon service to display icons.
  • Browsing Activity (browsingActivity): Declared because when you open the popup to save your current active tab, the active page domain is resolved to fetch its favicon preview.

Neither of these data types is ever collected, logged, or retained on any server operated by Bookmark Glass.

5. Browser Permissions Used

Permission Applicability Why It Is Needed
bookmarks All Editions To read existing browser bookmarks and save new bookmarks to your native bookmark folders.
storage All Editions To store your personal library links, reading list articles, and layout settings locally.
contextMenus All Editions To provide convenient right-click options ("Save to Bookmark Glass", "Save to My Library").
activeTab All Editions To obtain the active tab's title and URL strictly when you click the extension action or trigger a save.
scripting All Editions To inspect the active page's metadata (description and OpenGraph cover image) when initiating a save.
favicon Edge Edition To retrieve website icons locally from Edge's internal browser cache without external network requests.

6. Data Retention, Control & Deletion

  • Individual Items: You can edit or delete any saved bookmark, library link, article, tag, or folder at any time directly through the Bookmark Glass interface.
  • Complete Erasure: To delete all data associated with Bookmark Glass, simply uninstall the extension from your browser:
    • In Microsoft Edge: via edge://extensions
    • In Mozilla Firefox: via about:addons
    Uninstalling immediately purges all local storage.
